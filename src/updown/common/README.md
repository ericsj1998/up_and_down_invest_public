# `common` — 공용 계약 계층

**책임**: 도메인 모델(값 객체·열거형), 설정/시크릿 로딩, 로깅 기반, 시장별 비용 테이블(§12.7).

**하지 않는 것**: 판단·계산·I/O. 어떤 도메인 패키지도 import 하지 않는다 — 계층 순서의 바닥이다.

**왜 비용 테이블이 여기 있는가**: 백테스트(orchestration)·PaperAdapter(marketdata)·RR 순손익
계산(decision) 셋이 **같은 테이블**을 써야 한다(§12.7, §4.19). 가장 낮은 계층에 두어야
셋 모두가 import 할 수 있다 (plan P-3).

> 로직이 붙기 시작하면 `common` 이 아니라 도메인 패키지 소속이다. 비대화를 막는 유일한 기준이다.
