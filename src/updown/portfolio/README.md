# `portfolio` — Unified Portfolio (spec §4.18)

**책임**: 브로커·자산군을 가로지르는 현재 상태의 **사실** 집계 — 보유 종목, 평가금액,
버킷별 비중, 계좌 잔고. 읽기 전용이다.

**하지 않는 것**: 판단. "비중이 틀어졌으니 리밸런싱하라"는 §4.7 Allocation 의 몫이고
그것은 `decision` 에 있다.

**왜 analysis 보다 아래인가**: §4.6 RiskManager 가 입력으로 `PortfolioState` 를 요구하므로
`decision` 보다 낮아야 한다. 사실 집계는 아무 판단에도 의존하지 않으므로 낮게 두는 것이
자연스럽다 (plan D-6).

**왜 사실/판단을 쪼갰는가**: 한 패키지에 두면 `portfolio ↔ decision` 순환 참조가 생긴다.
스펙 §4.18 이 이미 "사실 / 판단"으로 나눠 뒀고, 그 구분을 패키지 경계로 승격시켰다 (plan P-2).
