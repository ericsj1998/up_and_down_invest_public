# `analysis/playbook` — 매매법 층

> 셋업 위에 있는 층. **선언·버전·성과 귀속의 단위**다.

## 책임

| 한다 | 안 한다 |
|---|---|
| 어느 매매법이 지금 도는지 고른다 | 손절·익절 값을 **확정**한다 (RiskManager 몫, 절대 규칙 #4) |
| 주력/보조 계열을 선언한다 | 런타임에 플래그를 고른다 |
| 충돌 처리 정책을 선언한다 | 주문을 낸다 |

## 🔴 같은 셋업이 국면에 따라 다른 매매법이다

```
order_block + RANGE      →  박스권 매매
order_block + UPTREND    →  눌림목 매매
```

옛 구조에서는 `order_block` 이 나오면 국면과 무관하게 후보였고, 그래서 상승장의
눌림목과 횡보장의 왕복이 **한 줄에 섞여 기록**됐다.

## ⛔ 구성을 바꾸면 새 버전이다

성과 귀속 키는 `id@version` 이다. 같은 이름으로 구성을 바꾸면 옛 성적과 새 성적이
한 줄에 섞인다 (§5.6.2).
