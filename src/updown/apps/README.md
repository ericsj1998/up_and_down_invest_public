# `apps` — 프로세스 진입점

**책임**: FastAPI 앱 구성·라우팅·미들웨어(`api`), asyncio 메인·스케줄러 등록·부팅
시퀀스(`engine`). 조립과 배선만 한다.

**하지 않는 것**: 계산·판단. 여기에 로직이 생기면 도메인 패키지로 내려보낸다.

**왜 2프로세스인가** (spec §2.1): **웹서버 재배포나 다운이 손절 감시를 죽이면 안 되기
때문**이다. api 를 재시작해도 engine 의 스케줄 잡은 끊기지 않아야 하고, 그것이 P0-9-6 의
검증 항목이다.

**동일 이미지·다른 커맨드**:

```
python -m updown.apps.api      # 웹
python -m updown.apps.engine   # 스케줄러 · 감시 루프
```

> engine 은 **단일 실행**이 강제된다. Redis 락(§12.5)을 획득한 인스턴스만 잡을 돌리고,
> 락을 잃으면 스케줄러를 즉시 정지한다.
